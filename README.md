# EclipseOS Vendor Files

This repository contains vendor-specific files for EclipseOS.

## Structure

```
vendor/eclipse/
├── config/
│   ├── common.mk              # Common configuration
│   ├── version.mk             # Version information
│   └── permissions/           # App permissions
├── overlay/                   # System overlays
├── bootanimation/            # Boot animation files
├── Android.mk                # Main makefile
├── vendorsetup.sh           # Setup script
└── README.md                # This file
```

## Usage

This vendor repository is automatically included when building EclipseOS.

## Version

- **Version**: 1.0
- **Base**: LineageOS 23.0 (Android 16)
- **Branch**: eclipse-16

- EclipseOS branding and versioning
- Custom app permissions
